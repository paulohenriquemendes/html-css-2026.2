# 💻 HTML e CSS — Repositório da Disciplina

Este espaço foi criado para acompanhar o desenvolvimento das aulas e reunir os materiais, exemplos e exercícios trabalhados ao longo da disciplina.

## 📚 Sobre a disciplina

Durante as aulas, vamos explorar os principais conceitos necessários para a criação e estilização de páginas web utilizando:

- **HTML** — estrutura e organização do conteúdo
- **CSS** — estilização, layout e apresentação
- Boas práticas de desenvolvimento
- Estruturação de páginas web
- Exercícios e exemplos práticos
